Hallucination Detector

A Streamlit app that fact-checks AI-generated answers against a curated CS and AI knowledge base. Paste any AI response, and the app extracts factual claims, retrieves relevant evidence via semantic search, and gives each claim a verdict: Supported, Weakly Supported or Unsupported.

View source on GitHub

How it works

  1. Claim extraction. GPT-4o-mini parses the AI answer into discrete factual claims.
  2. Semantic retrieval. Each claim is embedded and matched against a FAISS index built from the knowledge base.
  3. Verification. GPT-4o-mini evaluates each claim against the retrieved evidence.
  4. Scoring. A hallucination score from 0 to 1 is computed and a verdict is shown.

Knowledge base

Covers 19 core CS and AI topics: algorithms, data structures, databases, operating systems, networking, software engineering, testing, Git and CI/CD, cloud and DevOps, web development, cybersecurity, machine learning, deep learning, transformers, LLMs, embeddings, vector databases, RAG and AI safety. Documents are stored as plain text files, with references for each one.
