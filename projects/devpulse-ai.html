DevPulse AI

AI-powered developer analytics. Connect your GitHub repositories and get insight into PR health, review turnaround, commit patterns and weekly engineering trends, with an AI assistant that answers questions about your repo data.

View source on GitHub

Features

  • Auth. Email and password with bcrypt and JWT, plus GitHub OAuth.
  • Repositories. Connect any GitHub repo, with manual and webhook-triggered sync.
  • PR analytics. Merge rate, time to merge, review turnaround, weekly throughput and a stale-PR list.
  • Commit analytics. Frequency, contributors, an activity heatmap and Conventional Commits compliance.
  • AI. PR summaries, weekly engineering reports, a 0 to 100 repo health score and chat over your repo data.
  • UX. Light and dark theme, custom date ranges, CSV and JSON export.

Engineering

  • 293 automated tests: 146 on the server and 147 on the client.
  • GitHub Actions CI runs both test suites, the production build, the Docker image builds and Terraform validation.
  • AWS infrastructure is written in Terraform (ECS Fargate, RDS, ElastiCache). It has not been applied, so the app is not running on AWS.
